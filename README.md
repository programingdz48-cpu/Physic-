# المعلم في المستوي (Coordinate System in a Plane) 🚗📐

تطبيق تعليمي تفاعلي باللغة العربية لمادة الرياضيات، مصمم خصيصاً لطلاب مرحلتي التعليم المتوسط والثانوي لفهم واستيعاب درس **"المعلم في المستوي"** بطريقة تفاعلية وبصرية ممتعة.

---

## 🌟 مميزات التطبيق

- **مراحل تدريجية تفاعلية (Step-by-step Flow):** لا يمكن الانتقال للمرحلة التالية إلا بعد حل التحدي الحالي بشكل صحيح.
- **شبكة معلم تفاعلية (HTML5 Canvas):** رسم دقيق للمحاور (محور الفواصل $X$ ومحور التراتيب $Y$) والمبدأ $O(0,0)$، مع إمكانية تحريك سيارة بمؤثرات ورسوم حية.
- **تحدي القيادة العملي:** لوحة تحكم بالاتجاهات وأسهم لوحة المفاتيح لتوجيه سيارة التوصيل إلى إحداثيات الزبون `(-2 , 3)` مع فحص فوري للموقع وتقديم تلميحات ذكية.
- **تصميم متجاوب وحديث (Mobile-First):** خطوط عربية جميلة (Tajawal & Cairo)، وألوان عصرية مريحة للعين.
- **مؤثرات صوتية واحتفالية بدون إنترنت:** أصوات مدمجة تعمل بتقنية Web Audio API ومؤثرات قصاصات ملونة (Confetti) عند الفوز.
- **مستقل بالكامل:** مبني باستخدام Pure HTML, CSS, Vanilla JavaScript دون أي أطر عمل أو مكتبات خارجية معقدة.

---

## 🚀 طريقة التشغيل

افتح ملف `index.html` مباشرة في أي متصفح ويب حديث (Google Chrome, Microsoft Edge, Firefox, Safari).
