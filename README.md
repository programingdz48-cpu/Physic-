# المنصة التعليمية التفاعلية 🎓📐

منصة تعليمية تفاعلية باللغة العربية، تضم دروساً واختبارات قائمة على سيناريوهات واقعية ومحاكاة بصرية.

---

## 📂 محتويات المنصة

### 1. درس: المَعْلَم في المُسْتَوِي (`index.html`) 🚗
- **الموضوع:** الرياضيات (المعلم المتعامد والمتجانس، الفاصلة، الترتيبة، الإشارات).
- **المميزات:**
  - شبكة إحداثيات مرسومة بتقنية Canvas مع سيارة متحركة ومسارات وتدريجات دقيقة.
  - تدفق تدريجي يمنع الانتقال للخطوة التالية دون حل التحدي الحالي.
  - تحدي قيادة عملي عبر أزرار التحكم بالاتجاهات وأسهم لوحة المفاتيح لإيصال طلبية إلى النقطة `(-2 , 3)`.
  - مؤثرات صوتية عبر Web Audio API بدون أي ملفات خارجية.

### 2. كويز: أنواع الاتصال التنظيمي والمؤسساتي (`communication-quiz.html`) 🏢
- **الموضوع:** علوم الإعلام والاتصال / إدارة الأعمال والتنظيم.
- **المحتوى:** يغطي **16 نوعاً كاملاً** موزعة على 4 محاور رئيسية مع المصطلحات بالفرنسية:
  1. **حسب الاتجاه (Direction):** الأفقي (Horizontale)، العمودي (Verticale)، القطري (Diagonale).
  2. **حسب الجمهور (Public cible):** الداخلي (Interne)، الخارجي (Externe)، المؤسسي (Institutionnelle)، المجتمعي (Sociétale).
  3. **حسب الوسيلة (Moyen):** الشفهي (Orale)، الكتابي (Écrite)، البصري (Visuelle)، السمعي البصري (Audiovisuelle)، الرقمي (Digitale).
  4. **حسب الطبيعة (Nature):** الرسمي (Formelle)، غير الرسمي (Informelle)، المباشر (Directe)، غير المباشر (Indirecte).
- **المميزات:**
  - ملخص دراسي سريع قبل البدء (Accordion) قابل للفتح والإغلاق أثناء الكويز.
  - 16 سيناريو واقعي من بيئة العمل والشركات مع تلميحات توجيهية عند الخطأ دون حرق الإجابة.
  - شاشة نتائج وبطاقة مرجعية شاملة لكافة التعريفات مع إمكانية إعادة الاختبار بترتيب عشوائي.

---

## 🚀 طريقة التشغيل

افتح ملف `index.html` أو `communication-quiz.html` مباشرة في أي متصفح ويب حديث دون الحاجة لتثبيت أي برامج أو خوادم.
